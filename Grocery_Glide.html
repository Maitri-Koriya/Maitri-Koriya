Overview

Project Overview

Grocery Glide is an Android-based grocery shopping application developed as an academic project to gain practical experience in mobile application development and cloud-based services. Built using Java, Firebase, and Cloudinary, the application enables users to browse products, manage their shopping cart, and complete purchases through a clean and intuitive interface. The project focuses on creating a smooth shopping experience with secure user authentication, efficient product management, responsive navigation, and real-time data handling. Grocery Glide demonstrates practical skills in Android development, Firebase integration, cloud storage, and building user-friendly mobile applications.

Key Features

  • Secure login and registration with Firebase.
  • Browse products by category.
  • Add, update, and remove cart items.
  • Simple and secure checkout process.
  • Manage user profile and personal details.
  • Responsive and user-friendly interface.
